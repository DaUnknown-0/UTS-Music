# UTS-Music

Music for the Music panel of **TOR - Forgotten Fixes** (Useful TOR Stuff): looping tracks for the Role Draft, the menus,
the lobby, meetings and the reactor meltdown.

The mod downloads these files only when the player asks for it ("Load music" in the Music panel or the Music tab of the
Mod Manager) and checks every file against the size and SHA-256 in its built-in catalog. `catalog.json` lists the same
data for reference.

- `tracks/<kind>-<x>.ogg`: Ogg Vorbis, 44.1 kHz stereo, about 60 to 100 s, made to loop seamlessly.
- All tracks are synthesized in code (no samples, no recordings).

## Costumes

Forgotten Fixes checks size and SHA-256 of these packages at startup and downloads them when needed.

- `costumes/feeling-cute-v1.zip`: idle, walk and ladder frames with colour masks for the costume "Feeling Cute Blue Cat".
- `costumes/feeling-cute-v2.zip`: idle, walk and ladder frames with colour masks for "Feeling Cute Pawprint Cat" (cream paw bib, raised toy knife).
- `costumes/feeling-cute-v3.zip`: transparent overlay frames for "Feeling Cute Overalls": pastel overalls over the normal crewmate, with three Blue Cats (one on the head holding a red heart, one in the chest pocket, one on the strap). Idle, twelve walk frames and a back view for the ladder; player colour and the original visor stay visible.
