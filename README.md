# UTS-Music

Music for the Music panel of **TOR - Forgotten Fixes** (Useful TOR Stuff): looping tracks for the Role Draft, the menus,
the lobby, meetings and the reactor meltdown.

The mod downloads these files only when the player asks for it ("Load music" in the Music panel or the Music tab of the
Mod Manager) and checks every file against the size and SHA-256 in its built-in catalog. `catalog.json` lists the same
data for reference.

- `tracks/<kind>-<x>.ogg`: Ogg Vorbis, 44.1 kHz stereo, about 60 to 100 s, made to loop seamlessly.
- All tracks are synthesized in code (no samples, no recordings).
